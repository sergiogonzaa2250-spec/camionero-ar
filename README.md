# Camionero AR

MVP inicial de una PWA para planificar rutas de transporte pesado en Argentina.

## Stack

- Next.js App Router
- React
- TypeScript
- CSS responsive

## Ejecutar

```bash
npm install
npm run dev
```

Abrir `http://localhost:3000`.

## Estado

La interfaz y el perfil de vehículo funcionan. La evaluación de rutas es demostrativa y todavía NO debe interpretarse como información vial verificada.
